# 风机齿轮箱智能故障诊断系统

基于振动信号的旋转机械故障诊断系统，覆盖**边端采集 → 云端分析 → 前端展示**的完整链路，用于风机齿轮箱与轴承的状态监测和故障诊断。

## 系统组成

| 模块 | 目录 | 说明 |
|------|------|------|
| 云端后端 | `cloud/` | FastAPI 服务，负责数据接入、信号分析、诊断、告警与 WebSocket 推送 |
| 前端 | `wind-turbine-diagnosis/` | Vue 3 + Vite + Element Plus + ECharts 可视化界面 |
| 边端采集 | `edge/` | 读取现场或数据集振动信号，压缩后上传云端 |
| 文档 | `docs/` | 架构、算法、接口、部署、运维与现场资料 |

**诊断能力：** 轴承（包络分析、快速谱峭度图、CPW、MED、MCKD、循环平稳等）、齿轮（FM0/FM4/CAR/SER、行星齿轮箱解调等）、阶次跟踪、去噪与多方法集成投票，输出健康度、故障概率与维护建议。

## 快速开始

本机运行前端与数据回放，云端运行后端与数据库：

1. 双击仓库根目录的 `start.bat`，按提示选择数据集。
2. 浏览器打开 <http://127.0.0.1:3000>，使用访问密码登录。

完整步骤见 [快速启动说明](docs/快速启动说明.md)。

## 目录结构

```
CNN/
├── cloud/                     # 云端 FastAPI 后端
├── wind-turbine-diagnosis/    # Vue 3 前端
├── edge/                      # 边端采集与回放
├── data/                      # 数据集（不提交 Git）
├── docs/                      # 项目文档
├── scripts/                   # 运维调试脚本
├── tests/                     # 回归与评估测试
├── start.bat                  # Windows 一键启动
└── deploy.sh                  # 服务器一键部署
```
