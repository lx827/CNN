# 原生计算库完整扩展

本次以已有计算能力为范围，统一 C++ 数值实现，Python 保留对象适配与业务策略。
阈值判断、健康评分、告警、缓存与 HTTP 不下沉；研究表示继续保留研究身份。
数学参考使用对应官方 Python 库的实际源码，项目既有单位、有效区间和收敛状态继续有效。

## 模块与数据流

```text
公共数组与构建配置
  ├─ Fourier Plan → 频谱/STFT/倒谱/Hilbert、VMD、循环平稳/MSB
  ├─ 滤波与统计 → 小波、LMS、谱峭度、时域与趋势计算
  ├─ 矩阵分解 → MED/MCKD、ICA
  └─ 插值与包络 → EMD、相位/阶次、TSA

独立数学模块 → 公共 C++ 拥有型入口
               ├─ Python 薄绑定 → 现有 cloud 对象
               └─ C ABI 动态库 → 边端或其他宿主
```

输入在同步调用内借用；布局转换在调用边界完成。结果独立拥有，Python 数组持有
原生 owner。工作区由活跃调用独占，同规模迭代复用，临时 view 不作为永久结果。
FFT、滤波、分解等正常需要的工作副本保留；组合直接调用执行接口，不重复公式。

## 交付与验证

Windows/Linux x64 完成构建、必要数学对照、业务 P0 与实际性能检查。
ARM64 提供独立构建入口，本次不进行树莓派实机验证或边端部署。
外部 C++ 提供头文件和 CMake 使用入口；C ABI 与调用方按同版本配套升级。
后端选择由实际热点和目标工具链决定，所有算法与数值后端不新增内部线程池。
此页是本次设计与工作范围，已实现能力和验证记录以完成后的计算库文档为准。
