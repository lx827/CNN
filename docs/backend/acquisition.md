# DC24 云端服务契约

任务、上传、示波和 WebSocket 的外部字段见 [后端 API](../api/backend_api.md)；采集协议和文件格式见 [DC24 采集说明](../DC24_ACQUISITION.md)。本页只记录云端服务的稳定业务语义。

## 原始 counts 显示分析

`services/acquisition_analysis.py` 被整包上传和实时窗口共用，输入为未标定四通道 ADC counts，不修改原始波形，不进入设备故障诊断、健康评分或告警。

- 支持可选 FFT、总体/分段 RMS 和指定频带 Hilbert 包络。
- 频谱与统计在全长数据上计算；绘图摘要在计算后生成。
- 波形与频谱抽点保留极值及真实横坐标，只用于显示。
- 完整 NumPy 分析数组用于 `analysis_arrays.npz`，JSON 摘要用于 `analysis.json`；两者不得因显示点数不同而混淆。
- 包络频带必须满足 `0 < low < high < sample_rate/2`；非法频带明确失败。
- counts 不是加速度等物理标定量，响应与落盘单位必须保留这一事实。

独立 transforms/statistics 数值路径已随 #76 / PR #81 合并；频谱、分段统计、通用包络和显示抽点的数学语义统一见 [基础数值表示](../algorithms/numeric/INDEX.md)。

## 示波有界内存窗口

`LiveStore` 是线程安全的会话存储，示波样本不写入业务数据库或采样文件，除非用户显式启动“示波中保存”。

- 同一边端同时仅一个活跃会话；已结束会话只保留有界数量。
- 边端帧按序号接收，乱序和重复数据被丢弃。
- 实时窗口最多保留最近 2 秒，并只返回最近**连续**片段；网络缺口两侧不能拼成连续波形。
- RMS 历史、会话数量和内部 chunks 都有界；新帧推进 revision，作为 WS 推送依据。
- 快照排除内部大数组和上传私有状态；路由负责把不存在会话映射为 404。
- 会话状态、保存任务和停止终态由采集生命周期协调，上传完成前不能提前发布停止终态。

## 持久化边界

整包原始文件、可选分析摘要和完整数组属于采集任务产物，不等同于 `sensor_data` 业务批次。原始文件落盘根目录由 `ACQUISITION_DATA_DIR` 配置；数据库任务状态与文件系统产物需要按任务生命周期保持一致。
