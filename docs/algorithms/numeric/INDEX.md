## 数学目的

本族提供显示和诊断共用的基础表示：单边 Fourier 幅值/均方功率、STFT、通用 Hilbert 包络、实倒谱、总体/分段统计和绘图极值抽点。核心目标是让频率轴、时间轴、幅值归一化和物理单位可组合，避免不同路由各自实现相似数学。

## 适用与不适用场景

- FFT 幅值和 bin 均方功率适用于稳态或分段近似稳态表示；bin 功率不是 PSD，不能直接解释为物理功率。
- STFT 适用于时频显示和局部频率分析；零填充不提高物理频率分辨率。
- 通用带通 Hilbert 包络只生成时域表示，不等于轴承诊断包络 Pipeline。
- log-amplitude 实倒谱用于观察周期谱线对应的倒频率；显示峰不构成机械故障阈值。
- 总体/加窗统计用于描述输入记录，不自动形成健康评分。
- 极值抽点只用于绘图，不得用于 FFT、RMS、包络或故障评估。

## 输入、输出与单位

| 表示 | 轴与幅值语义 |
|------|--------------|
| Fourier 频谱 | 频率 Hz；周期 Hann 相干增益补偿的单边峰值幅值，单位同输入；bin 均方功率单位为输入单位平方 |
| STFT | 时间 s、频率 Hz；幅值数组形状为 `(frequency, time)`；线性幅值与 `20log10(amplitude+floor)` 显示分贝分开 |
| 通用包络 | 时间采样不变，幅值单位同输入；不做诊断低通、去包络 DC 或机械评估 |
| 实倒谱 | 非负倒频率轴 s，API 可换算 ms；幅值带符号，语义为去均值 log 幅值谱的实 IFFT |
| 总体统计 | Peak/RMS 与输入同单位；峭度、偏度、裕度、波形/脉冲/峰值因子无量纲 |
| 加窗/分段统计 | 窗口起点或分段中心为 s；窗口序列只含完整窗，分段 RMS 可保留实际长度末段 |
| 绘图抽点 | 两列 `(x,y)` 显示表示，保留原始横坐标与顺序，不是重采样信号 |

FFT 非 DC/Nyquist bin 幅值乘 2，DC 与偶数长度 Nyquist 不翻倍。整数周期正弦 $A\sin(\omega t)$ 的中间 bin 目标语义为幅值 $A$、均方功率 $A^2/2$；不去均值的 DC 常量 $C$ 为 $|C|$ 与 $C^2$，偶数点 Nyquist 信号 $A(-1)^n$ 为 $A$ 与 $A^2$。

`amplitude_unit` 必须如实描述输入，例如未标定 DC24 为 `ADC counts`；算法不负责物理标定。

## 必要前提

- 输入是一维、有限且满足各变换最短长度的采样；采样率有限且为正。
- STFT 窗长、重叠与 FFT 长度必须兼容，窗长不能超过记录；业务窗口缩短策略与纯变换分开。
- 通用带通包络要求合法频带位于 Nyquist 内；它不替代 [轴承包络契约](../bearing/INDEX.md) 的低通、故障目标和评估。
- 倒谱对数需要数值下限；log-amplitude 与 log-power 不得混称。
- 所有全长指标先于显示截断或抽点计算。

## Pipeline 组合

```text
全长有限信号
→ 必要的去均值/窗函数
→ FFT、STFT、包络、倒谱或统计表示
→ 全长指标与完整数组
→ 业务展示截断、dB 换算、单位换算或极值抽点
→ JSON/文件适配
```

DC24 显示分析可在完整数组落盘后生成摘要；抽点开闭不得改变完整数组。轴承诊断 Pipeline 与通用显示包络保持各自明确的后处理，不强行复用为同一诊断语义。

## 错误与不可判定语义

- 维度、长度、有限性、采样率或窗口参数非法时明确报错，不自动返回零谱或健康。
- 零分母统计需要约定数值回退并保留定义；该回退不是测量到的物理异常。
- 倒谱显示峰只表示局部表示峰，不证明故障；倒频率为零时不能计算有限对应频率。
- 展示截断只返回切片，不重算表示；全长指标必须先于截断完成。

## 复杂度与内存

FFT/STFT/倒谱主要为 $O(N\log N)$；STFT 额外存储随频率 bin 与帧数乘积增长。统计与绘图抽点为 $O(N)$。完整数组与显示摘要并存会增加持久化体积，但不允许为了降低显示点数而先破坏分析输入。生产线程和 5 秒业务限制见 [后端架构](../../backend/architecture.md)。
