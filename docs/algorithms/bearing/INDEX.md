## 数学目的

轴承局部缺陷的准周期冲击会调制结构共振。标准路径以带通信号 $y(t)$ 构造解析信号并提取包络：

$$e(t)=|y(t)+j\mathcal{H}\{y(t)\}|.$$

对去直流包络计算单边幅值谱，再根据轴承几何和转频得到 BPFO、BPFI、BSF、FTF 目标，评估载波、谐波和转频边带证据。几何公式与物理推导见 [经典算法原理](../../算法原理.md)。

## 适用与不适用场景

- 适用于存在可解调共振频带、记录长度足以分辨故障频率的恒速或缓变信号。
- 已知几何时可进行物理频率匹配；未配置几何时仅输出统计异常证据，不套用默认轴承型号。
- 快速变速连续轨迹尚未被轴承包络和物理频率评估消费，不能把轨迹中位数当作已完成角域补偿。
- 强随机冲击、转频谐波或齿轮确定性成分不必然代表轴承故障；需要结合谱峰归属、边带与其他证据。
- Kurtogram、CPW、MED/MCKD、TEO、谱峭度、SC/SCoh、小波和模态包络是现有高级方法族。#73 的纯数值拆分尚未合并，本页不提前声明其新函数契约。

## 输入、输出与单位

| 对象 | 稳定语义 |
|------|----------|
| 振动信号 | 一维有限采样；幅值单位由调用方如实给出，算法不做加速度或 ADC counts 标定 |
| 采样率、转频及其标准差 | Hz；转频标准差为有限非负数，用于扩大目标搜索的不确定性 |
| 轴承几何 | 滚动体数量为整数；滚动体与节圆直径使用一致长度单位；接触角为度 |
| 实际滤波频带 | Hz，返回裁剪后实际执行的频带，而非请求值的回显 |
| 包络谱 | 频率 Hz；幅值与输入信号同单位；`single_sided_amplitude` 单边峰值幅值 |
| 谱峰 SNR | 局部峰幅值/背景中位数的线性比，不是 dB |
| 谱功率代理 | 幅值平方和，单位为输入幅值单位平方；不是时域物理能量或 PSD |
| 低频与转频谐波比 | 无量纲；普通低频能量与转频整数倍窄带能量分别报告 |

非 DC/Nyquist bin 的幅值使用周期 Hann 相干增益补偿并乘 2，DC 与偶数长度 Nyquist 不翻倍。展示截断不改变完整有效频带上的分析和评估。

## 必要前提

- 标准包络输入至少 64 点、全部有限，采样率为正；滤波器参数与低通截止必须可实现。
- 请求频带会裁到 Nyquist 内可执行范围；低采样率使用相对 Nyquist 的默认频带，较高采样率优先 2–4 kHz，无法覆盖时退回相对频带。
- 物理故障评估需要有效标量转频。几何配置缺失与几何配置畸形不同：前者走无参统计，后者显式报错。
- 目标必须落在分析带宽内且可由频率轴分辨；共享 bin 不能同时作为多个目标的独立证据。

## Pipeline 组合

```text
原始/显式去噪信号
  → 去均值与实际带通
  → Hilbert 包络、低通、去直流
  → 完整单边包络幅值谱
  → 理论目标、局部峰与全局唯一归属
  → 载波/谐波/边带和统计指标
  → 独立阈值评估
  → 业务层展示截断与 JSON 适配
```

分析、评估和展示是三个阶段：重复评估已有分析结果不重新滤波或 FFT；改变展示上限不改变诊断结果。转速估计与故障增强信号的组合边界见 [阶次契约](../order/INDEX.md)。

### 高级方法族的组合边界

| 方法族 | 数学表示与单位 | 关键前提和限制 |
|------|----------------|----------------|
| CPW + 包络 | 倒频率为秒，编辑轴频/啮合对应梳状线后重构，重构信号保持输入单位 | 需要合理干扰频率；不是对所有噪声通用的白化器 |
| MED/MCKD + 包络 | FIR 输出保持输入单位；MED 最大化冲击性，MCKD 还使用故障周期 | MCKD 的周期样本与采样率、目标故障频率一致；无有效目标时不能伪造周期先验 |
| TEO/谱峭度选带 | TEO $\Psi[x_n]=x_n^2-x_{n-1}x_{n+1}$ 的量纲为输入单位平方；选带后的包络回到输入单位 | 瞬态增强也可能放大非故障干扰，必须继续验证周期性 |
| SC/SCoh | 谱频率与循环频率均为 Hz；矩阵维数为 `(alpha, frequency)`；SCoh 无量纲并归一化到 `[0,1]` | 频率分辨率受分段长度约束；无轴承几何时不能输出确定 BPFO/BPFI 类别 |
| 小波/EMD/VMD 包络 | 分解分量保持输入单位，选择评分无量纲 | 高峭度或高相关不证明目标故障；见 [分解契约](../decomposition/INDEX.md) |

SC/SCoh 通过分段复数交叉谱与 PSD 归一化观察循环频率处的相干证据。分段数、重叠和频率网格共同决定成本；阈值只适用于相应估计和背景定义，不能跨实现直接比较。

### 谱峰与边带证据

- 先在工程容差和转频不确定性范围内收集局部峰，再按幅值和归一化距离做全局唯一分配，避免最近 bin 不是局部峰而漏掉偏移真峰。
- 可分辨但没有局部峰的目标是有效阴性；共享 bin 或未唯一归属的目标不可评估。
- 边带密度分母只包含频带内、可分辨且可唯一归属的理论目标，包括未出现显著峰的可观测目标。
- 任一侧边带不可观测时，不对称度未知，不能用 0 代替。
- 载波显著性、边带显著性和最终显著性分别保留；BPFI 边带补救不被载波主导过滤覆盖。

## 错误与不可判定语义

| 情形 | 契约语义 |
|------|----------|
| 非一维、过短、NaN/Inf、非法采样率或滤波参数 | 明确参数错误，不跳过滤波、不返回健康 |
| 缺少转频或全部目标不可分辨 | 整体 `indeterminate`，不是健康 |
| 单目标超带宽、共享 bin 或不可分辨 | 该项 `not_evaluable`，显著性和 SNR 未知并附原因 |
| 可分辨目标没有局部峰且无归属冲突 | 已评估的有效阴性，显著性为假 |
| 任一侧边带缺失 | 不对称度及相应判定未知 |
| 无轴承几何 | 只给统计指标，不生成理论故障频率命中 |

统计显著性与物理峰显著性分别保存；非 SNR 指标使用一般强度分数，不统一冒称 SNR。

## 复杂度与内存

标准滤波、Hilbert 和 FFT 的主要成本为 $O(N\log N)$，额外存储为 $O(N)$。高级分解、谱相干和多方法集成会引入窗口、模态或方法数倍率。DataView 的业务截断、现有两线程池和后台串行分析是内存契约的一部分，见 [后端架构](../../backend/architecture.md)。
