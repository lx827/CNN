# 本地 emd 参考的原生 EMD 候选

## 参考身份与范围

参考为用户本地 `emd 0.8.1` 的 `emd.sift` 与 `_sift_core`，关键源码 SHA256 和事前冻结的局部/完整分解预算见 [参考契约](../../../tests/emd_reference_contract.json)。它和 `emd-signal/PyEMD` 不同；后者既有 benchmark 记录不作为本候选真值。

基础 EMD 的极值/包络、四种停止准则和完整多模态循环位于 C++；Python 新入口为 `cnn_compute.emd`。当前分支提供完整基础 sift；集成算法、mask 与 NHT/二层能力由独立工单分支继续验证，不把未合入能力列为已完成。生产默认和原仓库 SD/Rilling 候选保留。

## 数学与组合契约

严格局部极大/极小不把平台当作极值。默认 Rilling 边界延拓和三次 `splrep`，可选默认 `numpypad` 与 PCHIP；`mono_pchip` 在参考版本中与 PCHIP 同核。`splrep` 采用独立三次 B 样条拟合/求值，而非把 CubicSpline 改名。

包络模块可独立使用；基础筛分通过包络执行接口直接写上下包络，后者通过插值执行接口复用系数与带状求解缓冲。SD 判据分母为更新后信号能量；Rilling 通过时保留更新前 proto IMF，不能套用旧原生核的接受点。energy 与 fixed 保留各自含义。完整 sift 重新以原信号减所有当前模态之和计算残差，不用循环残差减法替换其舍入次序。

## 结果与失败

基础 sift 返回 `[samples, components]`；非零最终残差附在末列，不把所有列都称为振荡 IMF。上游 `return_residual` 实际未使用，兼容入口同样不根据此参数改变输出。详细入口返回独立拥有的各列、真实筛分次数和状态；`continue_flag` 表示能否继续提取，不等于收敛标志。

原生详细接口将初始极值不足表达为 `insufficient_extrema` 并保留原残差；参考 0.8.1 在部分此类输入会引用未定义变量，因此该失败域不宣称逐异常等价。迭代耗尽返回显式状态，常规数组入口抛 `ConvergenceError`；不伪造成功、零数组或回退结果。

外层 Rilling 参数在该参考版本中仅起启用作用，实际判断使用默认阈值且按源码的停止/继续方向使用；这一行为与 IMF 内 Rilling 的自定义阈值区分。

Rilling 与抛物线极值组合在参考中不能合法索引，原生公开拒绝该组合；抛物线与默认 numpypad 可以使用。自定义 NumPy padding 选项尚不支持，传入时明确报错。无延拓无法覆盖完整查询区间的输入明确失败。

## 内存与执行

输入只读借用，必要的可写筛分副本单独拥有。公开结果不指向工作区，各列移动转交 NumPy owner 后独立存活；`sift_detailed` 直接消费这些列可避免输出数组复制，`sift` 为二维兼容布局额外组装一次。下一轮工作区复用不会覆盖已返回结果。

基础筛分、包络、插值和带状求解临时空间随输入/节点规模线性增长，结果随模态数增长。工作区调用者独占，可以跨模态复用；库内不创建线程池、不持有全局可写工作区。SIMD 基座与实际验证架构见 [构建说明](../../native_compute.md)，跨架构能力与已测目标分别报告。

## 验证边界

维护测试 [test_compute_emd.py](../../../tests/test_compute_emd.py) 对照源码哈希一致的参考，覆盖默认及可选停止/插值/延拓、输入保留、输出所有权、并发隔离与失败。纯 C++ [接口测试](../../../tests/native/emd_contract.cpp) 检查公开/执行一致、大小规模复用及失败后复用。

[测量工具](../../../scripts/benchmark_emd.py) 在独立进程中交错三块执行参考与原生入口，包含 RNG/输入准备/输出布局成本，记录原始耗时、中位数/P95、OS 高水位和构建信息。输出保存在新建忽略目录或库外；这是本地受控比较，不复用旧同公式候选的生产采用门槛，也不替代真实数据效果和目标 ECS 2C2G 验收。
