# 本地 emd 参考的原生 EMD 候选

## 参考身份与范围

参考为用户本地 `D:/Python/Lib/site-packages/emd` 中 `emd 0.8.1` 的 `emd.sift` 与 `_sift_core`。局部/完整分解比较容差直接维护在测试代码中。它和 `emd-signal/PyEMD` 不同；后者既有 benchmark 记录不作为本候选真值。

基础 EMD 的极值/包络、四种停止准则和完整多模态循环位于 C++；Python 新入口为 `cnn_compute.emd`。mask 分支另提供多相位 mask、迭代 mask 和二层分解，Hilbert/NHT 作为独立变换模块复用；集成算法由独立分支验收。生产默认和原仓库 SD/Rilling 候选保留。

## 数学与组合契约

严格局部极大/极小不把平台当作极值。默认 Rilling 边界延拓和三次 `splrep`，可选默认 `numpypad` 与 PCHIP；`mono_pchip` 在参考版本中与 PCHIP 同核。`splrep` 采用独立三次 B 样条拟合/求值，而非把 CubicSpline 改名。

包络模块可独立使用；基础筛分通过包络执行接口直接写上下包络，后者通过插值执行接口复用系数与带状求解缓冲。SD 判据分母为更新后信号能量；Rilling 通过时保留更新前 proto IMF，不能套用旧原生核的接受点。energy 与 fixed 保留各自含义。完整 sift 重新以原信号减所有当前模态之和计算残差，不用循环残差减法替换其舍入次序。

## 结果与失败

基础 sift 返回 `[samples, components]`；非零最终残差附在末列，不把所有列都称为振荡 IMF。上游 `return_residual` 实际未使用，兼容入口同样不根据此参数改变输出。详细入口返回独立拥有的各列、真实筛分次数和状态；`continue_flag` 表示能否继续提取，不等于收敛标志。

原生详细接口将初始极值不足表达为 `insufficient_extrema` 并保留原残差；参考 0.8.1 在部分此类输入会引用未定义变量，因此该失败域不宣称逐异常等价。迭代耗尽返回显式状态，常规数组入口抛 `ConvergenceError`；不伪造成功、零数组或回退结果。

外层 Rilling 参数在该参考版本中仅起启用作用，实际判断使用默认阈值且按源码的停止/继续方向使用；这一行为与 IMF 内 Rilling 的自定义阈值区分。

Rilling 与抛物线极值组合在参考中不能合法索引，原生公开拒绝该组合；抛物线与默认 numpypad 可以使用。自定义 NumPy padding 选项尚不支持，传入时明确报错。无延拓无法覆盖完整查询区间的输入明确失败。

## mask、迭代与二层组合

`mask_sift` 和 `get_next_imf_mask` 的相位生成、去 mask、均值、模态循环都在 C++；支持显式归一化频率、首频几何递减、过零估频和 NHT 幅值加权瞬时频率估计。幅值可以是绝对量、原信号标准差比例或前一 IMF 标准差比例，也可逐模态指定。mask 的结果不额外追加残差列，不能沿用基础 sift 的末列解释。

独立 `cnn_compute.transforms` 提供一维解析信号、幅度归一化和 Hilbert/NHT 的相位、瞬时频率、幅值输出。NHT 使用三轮 combined/PCHIP 包络归一化后做 Hilbert，幅值取原信号的上包络；相位采用参考的升零相位、零填充中值滤波和一阶 Savitzky-Golay 导数。FFT 由 Eigen 后端执行，工作区保存计划与复数临时量，不为包络或相位分别重做 FFT。

`iterated_mask_sift` 的频率权重、边缘排除、收敛判据和收敛后平均在 C++。Python 仅在选择随机初始 mask 时用局部 `RandomState` 生成初始频率，不修改全局 RNG。保留参考 0.8.1 的结果单位差异：收敛后平均返回 Hz，外层达到 `max_iter` 返回归一化 cycles/sample。详细结果中的 `converged` 区分这两种退出；外层迭代上限保留最后有效模态，内部 IMF 筛分耗尽仍是失败。

二层分解接收 `[samples, first_layer_imfs]` 幅值列，C++ 内逐列组合。普通 `sift_second_layer` 仅覆盖参考的成功域：指定模态深度不超过输入列数，处理前该数量的输入列，每列结果必须装得进指定深度；上游在默认参数、越界输入列或额外残差列时可能报错，原生不静默裁剪来伪造等价。`mask_sift_second_layer` 处理全部输入列，每列依次丢弃最高频 mask。3D 输出在薄层一次组装并零填充空余列。

## 内存与执行

输入只读借用，必要的可写筛分副本单独拥有。公开结果不指向工作区，各列移动转交 NumPy owner 后独立存活；`sift_detailed` 直接消费这些列可避免输出数组复制，`sift` 为二维兼容布局额外组装一次。下一轮工作区复用不会覆盖已返回结果。

基础筛分、包络、插值和带状求解临时空间随输入/节点规模线性增长，结果随模态数增长。工作区调用者独占，可以跨模态复用；库内不创建线程池、不持有全局可写工作区。SIMD 基座与实际验证架构见 [构建说明](../../native_compute.md)，跨架构能力与已测目标分别报告。

mask 复用同一个成员筛分工作区及信号/相位缓冲区；独立任务各自准备工作区。迭代 mask 当前保存迭代历史以保持参考平均和零填充行为，内存随样本数、模态数和 `max_iter + N_avg` 的乘积增长，不能按单次基础 EMD 的线性常数估算。常规二维/三维兼容输出包含一次布局组装，详细列结果可以直接消费 owner。

## 验证边界

维护测试 [test_compute_emd.py](../../../tests/test_compute_emd.py) 对照所选 `emd 0.8.1`，覆盖默认及可选停止/插值/延拓、输入保留、输出所有权、并发隔离与失败。纯 C++ [接口测试](../../../tests/native/emd_contract.cpp) 检查公开/执行一致、大小规模复用及失败后复用。

[mask 差分测试](../../../tests/test_compute_emd_mask.py) 覆盖默认/显式/IF mask、幅值模式、奇偶长度 Hilbert/NHT、迭代收敛平均和上限退出、局部随机状态、二层成功域及输出所有权和并发隔离；[原生工作区测试](../../../tests/native/emd_mask_contract.cpp) 检查跨尺寸 prepare 后复用、公开/内部一致与并发任务隔离。具体通过状态与性能证据随 PR 验收记录，不以接口存在代替测试。

[测量工具](../../../scripts/benchmark_emd.py) 在独立进程中交错三块执行参考与原生入口，包含 RNG/输入准备/输出布局成本，记录原始耗时、中位数/P95、OS 高水位和构建信息。输出保存在新建忽略目录或库外；这是本地受控比较，不复用旧同公式候选的生产采用门槛，也不替代真实数据效果和目标 ECS 2C2G 验收。
