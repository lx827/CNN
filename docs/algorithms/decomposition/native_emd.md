# 本地 emd 参考的原生 EMD 候选

## 参考身份与范围

参考为用户本地 `D:/Python/Lib/site-packages/emd` 中 `emd 0.8.1` 的 `emd.sift` 与 `_sift_core`。局部/完整分解比较容差直接维护在测试代码中。它和 `emd-signal/PyEMD` 不同；后者既有 benchmark 记录不作为本候选真值。

基础 EMD 的极值/包络、四种停止准则和完整多模态循环位于 C++；Python 新入口为 `cnn_compute.emd`。当前分支提供完整基础 sift、ensemble_sift 与 complete_ensemble_sift；mask 与 NHT/二层能力由独立工单分支继续验证，不把未合入能力列为已完成。生产默认和原仓库 SD/Rilling 候选保留。

## 数学与组合契约

严格局部极大/极小不把平台当作极值。默认 Rilling 边界延拓和三次 `splrep`，可选默认 `numpypad` 与 PCHIP；`mono_pchip` 在参考版本中与 PCHIP 同核。`splrep` 采用独立三次 B 样条拟合/求值，而非把 CubicSpline 改名。

包络模块可独立使用；基础筛分通过包络执行接口直接写上下包络，后者通过插值执行接口复用系数与带状求解缓冲。SD 判据分母为更新后信号能量；Rilling 通过时保留更新前 proto IMF。energy 与 fixed 保留各自含义。完整 sift 递推更新残差，避免每阶重扫全部模态；性能优先，不承诺 Python 的逐操作舍入次序。

### EEMD 与 complete ensemble

ensemble_sift 的每个成员输入为 `x + std(x) * ensemble_noise * w`，实际运算次序保留参考的先缩放噪声再加信号。`noise_mode=flip` 还分解负噪声输入，将正负结果按参考原位广播规则平均；列数不兼容时明确抛错。成员模态数先按出现次数选择目标数，频次相同选较小者，再受 `max_imfs` 限制；逐列对列数至少达到目标数的成员平均，不把缺失模态补零参与聚合。

complete_ensemble_sift 先用原信号标准差归一化输入，并对每条标准正态噪声逐行 zscore、完整 sift。第一层对归一化信号注入按自身标准差归一化的噪声第一模态，提取各成员的局部均值并取平均；第一 IMF 是归一化输入减平均局部均值。后续注入对应噪声模态乘 `ensemble_noise * std(当前局部均值)`，噪声模态不再逐层标准化；新 IMF 为旧局部均值减新平均局部均值。最终附加局部均值残差，并将所有列乘回原信号标准差。

两者完整数值循环、归一化和聚合都在 C++。纯 C++ 入口显式借用逐行排列的标准正态噪声；Python 薄入口只用局部 `RandomState(seed)` 一次准备噪声，再传入 C++。显式种子的序列与参考 legacy RNG 一致；`noise_seed=None` 使用独立随机源，不消费全局 NumPy 随机状态。并发由上层调度，`nprocesses` 只接受 1。

## 结果与失败

基础 sift 返回 `[samples, components]`；非零最终残差附在末列，不把所有列都称为振荡 IMF。上游 `return_residual` 实际未使用，兼容入口同样不根据此参数改变输出。详细入口返回独立拥有的各列、真实筛分次数和状态；`continue_flag` 表示能否继续提取，不等于收敛标志。

原生详细接口将初始极值不足表达为 `insufficient_extrema` 并保留原残差；参考 0.8.1 在部分此类输入会引用未定义变量，因此该失败域不宣称逐异常等价。迭代耗尽返回显式状态，常规数组入口抛 `ConvergenceError`；不伪造成功、零数组或回退结果。

外层 Rilling 参数在该参考版本中仅起启用作用，实际判断使用默认阈值且按源码的停止/继续方向使用；这一行为与 IMF 内 Rilling 的自定义阈值区分。

Rilling 与抛物线极值组合在参考中不能合法索引，原生公开拒绝该组合；抛物线与默认 numpypad 可以使用。自定义 NumPy padding 选项尚不支持，传入时明确报错。无延拓无法覆盖完整查询区间的输入明确失败。

集成聚合没有单一 IMF 筛分次数，因此详细结果 `iterations` 为空，不伪造收敛次数。complete ensemble 的 `max_imfs` 明确限制振荡 IMF 数量，最后另附一列残差；原生循环先更新已生成模态数再检查上限，修正参考层号判断晚一轮、多提取一个 IMF 的缺陷。对照时只比较参考前目标数量的 IMF，残差由输入减这些 IMF 之和得到，使用相同数值容差。噪声对应层不足时抛 `IndexError`，不补零或循环复用噪声；常量输入或不可标准化噪声返回 `numerical_failure`，数组入口抛 `ConvergenceError`。参考在这些输入可能越界或传播非有限值，不宣称失败域逐异常一致。

## 内存与执行

输入只读借用，必要的可写筛分副本单独拥有。公开结果不指向工作区，各列移动转交 NumPy owner 后独立存活；`sift_detailed` 直接消费这些列可避免输出数组复制，`sift` 为二维兼容布局额外组装一次。下一轮工作区复用不会覆盖已返回结果。

基础筛分、包络、插值和带状求解临时空间随输入/节点规模线性增长，结果随模态数增长。工作区调用者独占，可以跨模态复用；库内不创建线程池、不持有全局可写工作区。SIMD 基座与实际验证架构见 [构建说明](../../native_compute.md)，跨架构能力与已测目标分别报告。

集成临时向量在 `EnsembleWorkspace` 中复用，每个活跃调用独占。EEMD 为选择成员模态数保留各成员分解；complete ensemble 缓存全部噪声分解，因此峰值还依赖集成次数和模态数，不声称只有 O(N)。输出聚合列独立于这些缓存，后续工作区复用与销毁不会覆盖已交接结果。

## 验证边界

维护测试 [test_compute_emd.py](../../../tests/test_compute_emd.py) 对照所选 `emd 0.8.1`，覆盖默认及可选停止/插值/延拓、输入保留、输出所有权、并发隔离与失败。纯 C++ [接口测试](../../../tests/native/emd_contract.cpp) 检查公开/执行一致、大小规模复用及失败后复用。

集成维护测试 [test_compute_emd_ensemble.py](../../../tests/test_compute_emd_ensemble.py) 对照 single/flip、两种插值、complete 的真实 IMF 上限，并检查固定种子重复、全局 RNG 不变、独立输出所有权、并发及失败传播。[集成 C++ 接口测试](../../../tests/native/emd_ensemble_contract.cpp) 直接复用同一工作区跨不同输入长度执行，检查输出活过工作区销毁、失败后恢复与并发隔离。

[测量工具](../../../scripts/benchmark_emd.py) 在独立进程中交错三块执行参考与原生入口，包含 RNG/输入准备/输出布局成本，记录原始耗时、中位数/P95、OS 高水位和构建信息。输出保存在新建忽略目录或库外；这是本地受控比较，不复用旧同公式候选的生产采用门槛，也不替代真实数据效果和目标 ECS 2C2G 验收。

2026-11-12 Windows/MSVC 的集成受控测量使用 1024 点合成 AM/FM 信号、4 个成员，三块交错运行、每块每后端 3 次。EEMD 中位耗时从 12.348 ms 降为 2.081 ms（5.93 倍），complete ensemble 从 31.715 ms 降为 4.888 ms（6.49 倍）；P95 分别为 12.711/2.127 ms 和 33.846/5.163 ms。两个后端在测量前通过逐模态数值预算。complete 参考请求 2 层、原生请求 3 层，均得到 3 个 IMF 加残差，匹配实际工作量。

同次进程 OS 峰值分别为参考/原生 105.87/34.67 MiB、109.52/34.88 MiB；该值包含各自依赖导入、预热及输出生命周期，不能解释为 C++ 临时分配量。这是单机小规模候选结果，未做真实数据与目标 ECS 验收，也不代表所有集成参数下的速度或内存上界。
