# 原生小波与 VMD

状态：#124 分解模块实现。Windows MSVC 19.50、x64 baseline 独立构建及定向数学、所有权、工作区检查通过；统一包注册与业务 P0 由整合 PR 验收。未声明 Linux、ARM64 或目标机器资源已通过。小波/VMD 是数值表示，提速不构成诊断有效性证明。

## 能力与默认路径

```text
cloud 小波适配 → cnn_compute.wavelet → CNN::wavelet → PyWavelets 独立 C 内核
cloud VMD 适配 → cnn_compute.vmd → CNN::vmd → CNN::fourier → pocketfft
cloud EMD/EEMD/CEEMDAN → 既有 Python 族编排 → 同公式原生单 IMF 筛分
```

小波和 VMD 的默认分解切换为原生 adapter；PyWavelets 与 NumPy adapter 仍可显式注入作数学参考，不在原生失败时静默回退。阈值评估、敏感分量选择、机械故障判定继续消费既有领域结果。小波阈值收缩本身属于数值计算，在 C++ 中执行。

EMD 默认 `NativeEMDImplementation` 已将归一化、多 IMF、原生随机数与 EEMD/Torres CEEMDAN 全部移入 C++，数学公式保留，随机序列兼容范围见 [完整原生业务 EMD](native_business_emd.md)。独立 `emd.sift 0.8.1` 家族是另一公式参照，没有被替换为业务默认。

## 小波数学与结果成本

复用官方 PyWavelets v1.8.0 的独立 C 滤波器、卷积、DWT/IDWT 源码，支持其全部内置离散小波族和九种延拓模式；运行时没有 Python/Cython 调用。MIT 源码归属见 [模块说明](../../../lib/wavelet/NOTICE.md)。PyWavelets 当前参考包为 1.8.0，导入模块为 `pywt`，实际计算来自其 `_extensions._dwt` 扩展。

C++ 执行多层 DWT、完全 WP、原时间轴分量重构，以及 MAD 通用阈值的 soft/hard/improved 细节收缩。近似带不收缩；归一化保证阈值不依赖幅值单位，MAD 没有绝对幅值下限。奇数长度只裁去延拓产生的尾点，不补零、不丢原记录尾点。`dmey` 是 FIR 近似，保留其固有重构误差。

公开 DWT/WP 兼容入口仍返回系数和全部全长分量，供现有领域模型使用。WP 不再为每个叶子复制整棵树，而是只沿该叶到根的合成路径重构。返回全部 `2**level` 条全长波形仍需要 O(N·2**level) 结果内存，这是此接口的输出成本。

独立计算库另提供系数分析对象及按索引选择重构入口：只保存叶系数，只沿所选路径合成，不先生成其他全长分量；选择规则由调用者决定。DWT 的系数顺序是 aL、dL、…、d1，WP 是自然路径序；频率顺序的逆 Gray 映射仍由领域适配处理。51200 点、db8、3 层 WP 的叶系数仅约 0.39 MiB，全部全长分量另需 3.125 MiB。轻量入口避免后者，不能把它与返回全部波形的接口直接当作同输出性能对照。

## VMD 数学与状态

公式依照 Dragomiretskiy & Zosso (2014) 的 ADMM，并核对官方 [vrcarva/vmdpy](https://github.com/vrcarva/vmdpy) 实现；本机独立参考安装包 `vmdpy==0.2`，实际模块 `vmdpy.vmdpy`。保留仓库现有幅值归一化、奇数镜像、中心 Hz、显式前导窗口和未收敛语义，不继承参考程序保存全部轮次频谱、丢弃奇数尾点或少返回最终一次更新的问题。

模态按连续的非负频点存储，仅保留两轮。负频在 ADMM 中严格为零，因此省去该半区计算和存储；最终按实信号共轭对称恢复频谱。频域更新、中心与差分归约复用预分配工作区；分母保持实数，避免不必要的通用复数除法。FFT 仅在输入变换和最终模态重构时调用，FFT 后端的临时空间按其自身实现计入。

常量信号为 `indeterminate/zero_variance`，保留原有效窗口残差；迭代耗尽保留研究表示但 `converged=False`。数值失败有明确状态，无效的模态、中心和历史数组为空，不能观察未初始化结果。失败后 Workspace 可复用；已清空的 Result 再执行前需重新准备。既有业务质量门控继续拒绝未收敛表示用于有效诊断。

N 为有效窗口，M=N+2·floor(N/2)，P=ceil(M/2)。两轮模态频谱为 `2·P·K` 个 complex128；默认 N=51200、K=5 时为 7.8125 MiB，原全频两轮为 15.625 MiB。另有频谱、对偶量、残差和 FFT 工作区；模态结果为 N·K 个 double，历史容量为 max_iterations·K 个 double。不把这份数组算账称为进程峰值。

## 所有权与执行接口

`lib/wavelet/api.hpp` 与 `lib/vmd/api.hpp` 是公开和内部执行契约的唯一签名来源。公开入口检查前提、准备独立拥有型输出和 Workspace，内部执行入口复用同一实现。调用同步借用连续输入；必要的归一化、镜像和系数存储是算法工作副本。工作区每个活跃调用独占，不创建线程池。

NumPy 连续 float64 输入借用，其他 dtype/布局只在 Python 边界集中适配。C++ 结果通过 capsule 转交 Eigen owner，重排形状使用 NumPy view；VMD 历史 view 只显示有效轮数，底层仍保留预分配容量。轻量小波系数 view 为只读且持有原生系数对象；对象销毁或下一次独立计算不会破坏已有 view。

## 定向证据

`tests/test_native_wavelet_vmd.py` 的五组检查覆盖七个离散族、九种边界、奇偶长度、WP 自然路径/频率映射、轻量选重构、三种阈值及幅值尺度、VMD 的 DC/tau/窗口、收敛状态、输入保留和输出生命周期。C++ `tests/native/wavelet_vmd_contract.cpp` 检查内部执行与公开入口一致、重复执行的缓冲指针、失败输出和跨规模准备。

官方 vmdpy 0.2 的 1024 点双频参考与原生结果：模态归一化 L2 差 8.26×10⁻⁸，中心最大差 2.69×10⁻⁷ Hz。不要求官方每步求和、迭代末位或 RNG 序列相同。

2026-11-13 Windows MSVC x64 baseline 的一次本地定向测量：51200 点合成振动、db8、WP/DWT 三层；VMD K=5、最多200轮。对每个后端预热一次、记录三次完整 cloud 公开调用，含领域适配及结果转交，排除导入；表中是三次中位数。

| 入口 | Python 参考 | 原生 | 比值 |
|------|-------------|------|------|
| DWT 全分量 | 2.284 ms | 1.640 ms | 1.39 倍 |
| WP 全分量 | 14.088 ms | 2.825 ms | 4.99 倍 |
| 小波阈值去噪 | 2.181 ms | 2.035 ms | 1.07 倍 |
| VMD | 5655.650 ms | 261.544 ms | 21.62 倍 |

VMD 两个后端都达到200轮且未收敛，此项仅比较同一计算预算，不宣称得到了质量接受的去噪信号。小波底层参考本来就是 C 扩展，因此阈值路径没有明显数量级提升。

另用各自全新进程单次调用读取 Windows OS PeakWorkingSetSize：WP 为 56.44→42.41 MiB，VMD 为 80.72→58.62 MiB，包含共同的导入、输入及运行时。该少量样本不是生产 SLO、云端验收或纯工作区节省证明。原始计时、临时构建和进程输出留在忽略目录，不提交自动报告或二进制。
