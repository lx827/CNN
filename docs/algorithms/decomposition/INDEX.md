## 数学目的

分解方法把信号表示为频带系数或本征模态，以便抑制噪声、定位共振频带并选择含冲击信息的分量。小波阈值通过系数收缩抑制噪声；小波包提供完整频带划分；EMD 族通过局部极值筛分得到 IMF；VMD 通过频域变分优化得到带限模态。

本模块的契约是“表示与选择”，不是单独的故障诊断。故障证据仍需包络、阶次、机械运动学或统计评估。

## 适用与不适用场景

| 方法族 | 适用 | 主要限制 |
|------|------|----------|
| DWT 阈值 | 宽带噪声、需要较低计算成本的预处理 | 小波基、层数和阈值会影响冲击保留；不是机械故障判别器 |
| 小波包 | 需要完整频带能量、熵或敏感节点选择 | 固定节点随转速变化可能跨越目标频率；层数增加提高成本 |
| EMD/EEMD/CEEMDAN | 非平稳信号、无法预设中心频率的探索性分解 | 模态混叠、端点效应、集成次数和筛分停止准则影响结果 |
| VMD | 目标频带或模态数有合理先验 | 模态数与惩罚因子需预设；不保证每个 IMF 都有独立物理意义 |
| S-G、LMS、级联 | 平滑或特定参考噪声/联合降噪 | 不能无条件替代分解；可能平滑冲击或引入滤波失真 |

固定频带示例只适用于相应采样率和工况。理论“抗噪”不等于已在现场数据验证。

## 输入、输出与单位

- 输入为一维有限时域采样和正采样率；采样保持原物理单位或 ADC counts，不在分解层偷偷标定。
- 小波系数、IMF 和重构信号保持输入幅值单位；频率轴 Hz，阶次轴 revolution$^{-1}$。
- 能量系数为输入单位平方，能量占比、相关系数、归一化熵和选择评分无量纲。
- 峭度必须说明采用 Pearson（高斯为 3）还是 excess（高斯为 0）约定；当前诊断组合通常使用 Pearson 口径。
- 输出应区分完整分量集合、选中分量、重构信号、残差和选择元数据，不把选择评分当作故障概率。

## 必要前提

- 分解层数受记录长度和小波滤波器长度约束；不可机械使用固定 5–7 层。
- EMD 族需要足够极值与合理端点处理；短记录或近单调信号可能无法形成有意义 IMF。
- VMD 需要模态数、惩罚因子和停止条件；高模态数与长记录必须计算内存账。
- 敏感分量选择需要可解释的评分与回退规则。高峭度可能来自随机干扰，高相关也可能保留强正常啮合。
- 用于转速估计的信号与用于故障增强的信号应按 [阶次契约](../order/INDEX.md) 分离，避免分解改变转速证据。

## Pipeline 组合

### 降噪

```text
去均值/去趋势 → 小波、EMD 族、VMD 或显式级联
→ 分量评分与选择 → 重构 → 下游包络/阶次/统计
```

### 轴承包络

```text
原始信号 → DWT/WP/EMD/VMD 表示 → 敏感频带或 IMF
→ Hilbert 包络与谱分析 → 轴承物理/统计证据
```

### 小波包能量

```text
完整小波包树 → 节点能量 $E_{j,k}$ → $p_{j,k}=E_{j,k}/\sum_mE_{j,m}$
→ 熵或敏感节点 → 齿轮/轴承辅助证据
```

### 自适应滤波、盲源分离与选择

- LMS/NLMS/VSSLMS 输出与输入同单位，步长和延迟参考决定稳定性。由单通道延迟构造的参考不等于独立噪声传感器，不能声称必然分离所有背景噪声。
- FastICA 输入为 `(samples, observed_channels)`，输出独立分量没有天然物理顺序；峭度最大只提供候选。单通道 VMD-ICA 是数值扩展，不会创造真实多测点 observability。
- 敏感分量评分可组合相关、峭度、包络熵、能量比、中心频率与目标频率匹配。各评分先定义量纲和归一化，再组合；综合分数不是故障概率。
- 选择结果必须保留索引、评分和回退原因。空选择、分量不足或评分并列时不得凭固定索引宣称故障分量。

详细频带公式、理论示例和历史伪代码保留在 [小波与模态分解理论](../wavelet_and_modality_decomposition.md)；其中示例不是当前函数签名。

## 错误与不可判定语义

- 非法采样率、非有限输入、不可实现层数或模态参数应明确报错，不返回“健康”。
- 无法形成有效分量或没有分量满足选择条件时，应显式记录空选择或回退原因；不得把随机分量解释成故障。
- 回退到峭度最大分量只表示选择策略，不证明该分量含目标故障。
- 分解成功不等于诊断成功；缺少机械参数时下游只能给统计异常。
- 集成噪声实现需要固定种子或记录随机性，否则验证结果不可直接逐样本复现。

## 复杂度与内存

小波类通常约为 $O(N)$ 至 $O(N\log N)$，小波包随层数增加节点和系数存储。VMD 约为迭代次数、模态数与 FFT 成本的乘积；EMD 受筛分次数影响，EEMD/CEEMDAN 再乘集成次数。任何级联都按阶段累计峰值内存。生产环境限制模态数、记录长度和并发，禁止并行展开全部组合，见 [后端架构](../../backend/architecture.md)。
