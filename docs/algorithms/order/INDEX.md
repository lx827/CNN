## 原生计算实现（#126）

标量转速候选仲裁、FFT 自相关、STFT 脊线、梯形相位积分、线性等角重采样和阶次幅值谱由 `cnn_compute.rotation` 调用 `lib/rotation/`。Python 保留结构化对象、工况选择和 Pipeline 组合；不存在按失败静默返回 Python 算法的分支。周期 Hann 单边幅值计算与公共数值模块共用同一内部执行入口。

STFT 逐帧复用窗、FFT Plan 和临时频谱，仅保存可靠脊线及最终连续轨迹，不持有完整时频矩阵。输入同步借用；结果通过独立 owner 交给 NumPy，返回后的数组不受后续工作区复用影响。各活跃调用独占工作区，不另建线程。Windows MSVC 的数值向量、公开调用性能与所限内存测量见[原生验收记录](native_rotation_validation.md)；该记录不声明 Linux、ARM 或目标服务器资源已验收。

## 数学目的

将等时间采样振动转换为等转角表示，使旋转机械在变速时的轴频、啮合及故障调制落在稳定阶次上。累计转数和相位为

$$r(t)=\int_0^t f_r(\tau)\,d\tau,\qquad \theta(t)=2\pi r(t).$$

在 $r_k=k/N_{rev}$ 处插值得到角域信号，再以单边幅值 FFT 得到阶次谱。模块同时负责标量转频候选、逐帧局部估计和连续转速轨迹，不将三者混为同一种转速证据。

## 适用与不适用场景

| 路径 | 适用 | 不适用或限制 |
|------|------|--------------|
| 恒速 | 有准确已知转频 | 未知或非法转频不得填默认值 |
| 缓变多帧 | 至少两个有效局部估计，保留帧 CV 不超过阈值 | 结果只是逐帧谱平均，不是连续相位跟踪 |
| 快速变速 | STFT 中存在可靠连续 1×轴频脊线 | 无可靠脊线、持续越界或相位不可积分时不可判定 |
| 自动路径 | 需要区分缓变与快速变速 | 单帧标准差为 0 不能证明恒速；slow 失败不能直接保留其谱 |

轴承故障频率本身不是轴频证据。缺少可观测 1×轴频或其调制证据时，不得按 BPFO 与标称转频比例反猜转速。当前轴承与齿轮下游仍要求标量恒速/缓变输入，快速变速完整补偿只由阶次路径提供。

## 输入、输出与单位

| 对象 | 稳定语义 |
|------|----------|
| 输入与估计信号 | 一维等长采样；估计信号使用原始/去趋势信号，重采样信号可为显式去噪结果 |
| 采样率、转频 | 分别为 samples/s、Hz；搜索范围是明确工况前提 |
| 局部估计 | 帧时间秒、频率 Hz、可靠/保留掩码；不可靠帧以缺失值和掩码排除 |
| 连续转速轨迹 | 时间秒、频率 Hz，并记录实际 STFT 窗和物理频率分辨率 |
| 相位轨迹 | 累计转数 revolution，从零开始严格递增；弧度相位按需为 $2\pi r$ |
| 角域信号 | 采样位置轴为 $k/N_{rev}$，单位 revolution；样本保持输入幅值单位 |
| 阶次谱 | FFT bin 轴为 $kN_{rev}/N$，单位 order/revolution；幅值为输入单位下的单边峰值幅值 |

角域采样位置轴与 FFT 阶次轴是两个不同坐标，禁止互相替代。非 DC/Nyquist bin 使用 $2|X_k|/\sum w$；DC 和偶数长度 Nyquist 不翻倍。对整数周期正弦，目标 bin 返回其峰值幅值。

## 必要前提

- 恒速路径需要有效正标量转频；自动路径需要可观测的转速证据和合理搜索范围。
- 每转采样点数决定角域 Nyquist 阶次，最大分析阶次必须低于该上限。
- 局部帧的可靠性与保留性分开；MAD 异常帧容差包含相对和绝对下限，避免 MAD=0 时吞掉真正离群帧。
- STFT 物理分辨率为 $f_s/nperseg$。零填充和抛物线插值只细化表示或峰位置，不提高物理分辨率。
- 可靠脊线才能插值为连续转速；边缘只接受短距离、有依据的外推，持续边界风险和内部越界不可忽略。

## Pipeline 组合

### 恒速

```text
有效标量转频 → 等角时间坐标 → 线性插值 → 相位轨迹 + 角域信号 → 单边阶次谱
```

### 缓变多帧

```text
逐帧候选与仲裁 → MAD 异常帧剔除 → 各保留帧独立等角采样/FFT
→ 公共 FFT 阶次轴插值 → 幅值平均
```

结果携带局部估计和平均谱，不携带连续相位或单一角域信号。

### 快速变速

```text
STFT 可靠脊线 → 连续转速轨迹 → 梯形积分相位
→ 等相位线性插值 → 单边阶次谱
```

自动路径先尝试缓变；有效帧不足、CV 超阈值或 slow 不可判定时继续 fast。fast 也失败则返回不可判定，不能保留 slow 谱冒充成功。

## 错误与不可判定语义

- 无有效信号、搜索频带或显著候选时返回不可判定，不返回搜索下限、10 Hz 或其他默认转速。
- 不可靠局部帧不参与中位数、标准差或 CV 判定。
- 快速变速任一步失败，整个快速路径不可判定，不退回标量恒速。
- 自动路径最终失败保留原因，不输出伪造的正常阶次谱。
- 结构化结果中的工况拥有最终前提决定权；调用方先从轨迹摘要出标量，也不能使快速变速轴承/齿轮分析变成合法恒速输入。
- HTTP 如何映射不可判定由 [API 文档](../../api/backend_api.md) 规定；算法层不依赖 HTTP 异常类型。

## 复杂度与内存

恒速插值与 FFT 为 $O(N\log N)$，存储 $O(N)$。多帧和 STFT 增加帧数倍频谱存储；连续轨迹、相位和角域信号均为 $O(N)$ 额外数组。窗长由目标频率分辨率、最长窗时长和记录长度共同限制，不能为追求分辨率无限增长。业务 5 秒截断与串行执行见 [后端架构](../../backend/architecture.md)。
