## 数学目的

组合复用 VMD、Hilbert AM/FM、连续振动分离（CVS）、MED、调制信号双谱（MSB）、ICA 与 WP 能量熵，以观察不同表示下的调制和统计量。各流程显式保留实际阶段输出，分析与评估分开；已有指标重评不重新分解或计算频谱。

### AM/FM 与 MSB 定义

解析信号 `z=hilbert(x-mean(x))` 给出 AM 包络 `a=abs(z)` 和相邻采样中点瞬时频率 `f=diff(unwrap(angle(z)))*fs/(2π)`。AM 与 FM 分别生成频谱，搜索调制频率或相应参考轴阶次，不在解调谱中搜索原始载波的 `mesh±n*rot` 位置。

本项目 MSB 采用 Guo 等（2018）Eq.10 的**四阶调制信号双谱**：

$$M(f_c,f_m)=E[X(f_c+f_m)X(f_c-f_m)\overline{X(f_c)}^{\,2}].$$

先跨分段复平均，再取 `abs(M)`。常规三阶双谱 `E[X(f1)X(f2)conj(X(f1+f2))]` 是不同表示，不把工单中旧称谓或三阶频率关系当作该 MSB 定义，也不为名词额外增加无用三阶入口。MSB 只计算显式有限载波/调制网格，切片峰与背景使用同一四阶幅值。

## 适用与不适用场景

| 组合 | 适用前提 | 限制 |
|------|----------|------|
| VMD→AM/FM | 合法定轴/行星几何、明确恒速、啮合附近可用模态 | 中心频率接近啮合不证明模态具有唯一物理来源；幅值零点使相位无定义 |
| MSB | 足够分段与可分辨、带宽内的载波/调制频率对 | 相位耦合不等于故障；先 abs 后平均会丢失非耦合抵消 |
| CVS→MED→MSB | 单行星空间通过窗口、真实连续相位、全圈覆盖和多个独立重组周期 | 不能以载波 TSA 或齿数推算相位零位替代 CVS |
| VMD→ICA→选择 | 足够数值秩、ICA 收敛和可解释逆映射 | 单通道模态形成虚拟观测，不创造真实空间可观测性 |
| MSWPEE | 可实现尺度/层数、非零节点能量 | 块平均粗粒化不是抗混叠重采样，不据混叠位置命名故障 |

当前组合均为 `research_only=true`、`production_eligible=false`，没有已标定故障阈值。计算成功也不生成生产健康分、故障概率或独立投票。

## 输入、输出与单位

| 对象 | 稳定语义 |
|------|----------|
| 振动与几何 | 一维有限输入、采样率 Hz；机械参数来自对应对象，幅值保持输入单位 |
| VMD 中心 | Hz，按原采样率从内部归一频率换算；沿用分解有效区间 |
| AM | 包络/谱幅为输入幅值单位 |
| FM | 瞬时频率与其谱幅为 Hz；序列长 N−1，位于相邻采样中点，不补尾值 |
| 调制目标 | Hz 与相对声明参考轴的阶次分别保留；定轴为轴频，行星为运动学事件候选 |
| MSB | 复均值与幅值为输入单位四次方；峰/背景同量纲，归一相干及背景比无量纲 |
| CVS 相位/方位 | rad，两个相位与原样本逐点对齐，含真实零位；编号对应明确行星布局 |
| CVS 重组 | 新有效采样率为相对自转 Hz × 每转点数，幅值仍为输入单位；保存源窗口和独立圈数 |
| ICA | 内部白化坐标无天然物理刻度；每个源逆映射到观测坐标后再恢复输入幅值单位 |
| 多尺度熵 | 块平均后的采样率 `fs/scale`；节点重构能量为输入单位平方，归一熵无量纲 |

Pipeline 保存阶段状态、原因、表示、指标、参数与共同 `evidence_family=shared_signal_decomposition_demodulation`。展示抽点只在研究边界发生，不回写分析输入或完整数组。

## 必要前提

- AM/FM 使用明确 `ScalarSpeed` 和合法对象几何，不用快速变速轨迹中位数替代恒速。VMD 模态中心需在啮合附近，采样率和有效区间与输入一致。
- MSB 载波和调制频率为正，`fc-fm>0`、`fc+fm<=Nyquist`；低于物理分辨率或没有有效频率对时不可判定。请求坐标和实际 FFT-bin 坐标均保留，不把超带宽目标夹到边界。
- CVS 必须提供 carrier 连续相位、所选行星相对行星架的连续自转相位、行星空间方位、编号、传感器方位和通过窗口。相位逐点同轴、运动学一致、窗口不重叠；不同通过片段须覆盖完整行星自转圈。
- CVS 每完成全圈就清空累加器，再用后续窗口形成另一个独立圈；不复制一个平均圈伪造长记录。当前均匀时间重组只支持恒定相对自转且输出采样率不低于原输入。
- ICA 数值秩与收敛显式检查；原始统计、排序、重构与故障阈值仍遵守 [分解契约](../decomposition/INDEX.md)。

## Pipeline 组合

```text
VMD → 啮合邻近模态 → AM 与 FM → 各自调制谱/候选峰

分段复 FFT → 四阶复乘积 → 复平均 → 幅值/相干 → 同量纲切片背景

真实相位/空间窗口 → CVS 独立全圈重组 → MED.signal
→ 使用 CVS 新采样率的 MSB → 原始研究指标

VMD.modes.T → SVD 白化 → ICA → 源逆映射到观测单位
→ 复用敏感分量评分/选择

每尺度块均值粗粒化 → fs/scale → 公共 WP 分解
→ 原时间轴节点重构能量熵 → 多尺度指标向量
```

各组合 analyze 负责阶段和指标，evaluate 只消费已有指标。当前无可信故障阈值，evaluate 返回 `not_evaluable`、结论 `unknown`，原始指标的 warning/critical 为未知。多条共享信号、分解或解调后端的流程不因方法数增加而成为独立证据；生产编排必须拒绝其投票和评分。

## 错误与不可判定语义

- 输入非法或资源参数越界明确拒绝；阶段失败保留阶段名与原因。
- 缺 CVS 实测相位、覆盖不足或空间对齐不成立，`signal=None`，不回退 TSA 或原信号并保留 CVS 标签。
- VMD/MED 未收敛可以保留研究近似表示并标记 `approximate`，不能当作质量通过或可告警；ICA 秩亏/未收敛明确不可判定。
- 计算状态与研究评估状态分开。`computed` 不等于已诊断，零能量/空结果/带宽不足不构造健康。
- 原始指标可见，生产故障指标/概率为空、健康分为空、结论未知；研究入口不写入生产诊断缓存或发送诊断告警。

## 复杂度与内存

VMD、ICA、MED 各有模态、迭代、矩阵倍率；MSB 按请求网格而非全二维计算。研究入口先限制最多 5 秒，再串行执行阶段；VMD 模态不超过 5、显式计算窗口不超过 51200 点，其他阶段的迭代、滤波长度、尺度和网格均有上限。与生产共用 2C2G，不能因研究用途新增并行线程或取消上限。性能基线与原生移植仍归 #79。

## 验证向量与验证状态

`cloud/tests/diagnosis/algorithms/test_composite_pipelines.py` 的 13 个独立向量已由实现方验证；文档轮次不重复运行。覆盖 AM 真值 0.4、FM 调制幅 5 Hz、四阶 MSB 已知耦合值 1/16、交替非耦合相位复均值抵消小于 1e−12、ICA 已知源相关大于 0.99/逆映射单位、Haar 能量分布 `(0.2,0.8)` 手算熵、CVS 空相位/覆盖不足与实际串联。

已记录的消融：真实 VMD 后 AM 幅值 0.387672558，去掉 VMD 直接解调为 0.395397808，真值 0.4；这不证明 VMD 更优。CVS 产生 7 个独立重组圈，去掉 MED 后 MSB 幅值向量 L2 差约 0.0150640224；原链 MED 未收敛，只能标 approximate。去掉 CVS 所需相位后不可判定，不能以原信号替代并计算同名结果。

这些是公式与阶段因果的合成证据，不是分类准确率、真实故障检出效果或生产就绪证明。真实数据与阈值校准归 #78；公开 API/前端验证在最终接入提交后同步到 [测试索引](../../tests/INDEX.md)。
