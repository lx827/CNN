## 数学目的

齿轮故障通过啮合刚度变化产生调幅、调频和局部冲击。定轴诊断围绕啮合频率 $f_{mesh}=Zf_r$ 及其转频边带，结合角域时域同步平均（TSA）、残余/差分信号、归一化矩和倒谱指标区分局部损伤与分布性磨损。

行星箱还需处理多行星轮、时变传递路径和行星架调制，不能把定轴箱的 1 阶边带间隔与阈值直接套用。核心公式和文献见 [经典算法原理](../../算法原理.md)。

## 适用与不适用场景

- 定轴 TSA、FM0/FM4/M6A/M8A、NA4/NB4、SER/CAR 与边带分析适用于有可靠标量转频和齿数的恒速/缓变记录。
- 无齿轮参数时只允许一般统计异常提示，不能计算可信啮合频率、故障轴位置或物理故障类型。
- 行星窄带/全频带/TSA/高通包络、VMD AM-FM、SC/SCoh、MSB 与 CVS+MED 是不同证据路径，不应以单一包络峭度代替全部故障形态。
- 快速变速连续轨迹尚未被齿轮 TSA 与行星解调消费；不得把轨迹中位数当作已补偿恒速输入。
- 多行星轮健康样本天然具有丰富边带；定轴 SER 阈值和“边带多即故障”的解释不适用于行星箱。
- 理论阈值不是跨数据集通用诊断保证，必须结合设备基线和验证状态。

## 输入、输出与单位

| 对象 | 稳定语义 |
|------|----------|
| 振动与采样率 | 一维有限信号；采样率 Hz；幅值保持输入单位 |
| 转频 | Hz 的有效标量；快速变速轨迹不是当前齿轮模块的合法替代 |
| 定轴齿数 | 无量纲整数，用于计算啮合频率/阶次和故障轴边带 |
| 行星参数 | 太阳轮、齿圈、行星轮齿数及行星轮数量；各特征阶次相对约定参考轴 |
| 阶次谱 | 阶次轴 revolution$^{-1}$，幅值归一化遵循 [阶次契约](../order/INDEX.md) |
| TSA/残余/差分信号 | 角域等采样序列，幅值与输入一致；平均转数与窗函数影响统计结果 |
| FM0/FM4/M6A/M8A/NA4/NB4/SER/CAR | 无量纲指标；NA4/NB4 的历史基线缺失语义必须显式保留 |
| 边带与故障证据 | 频率/阶次、幅值、线性背景比、可观测性和阈值状态分别表达 |

## 必要前提

- 转速、齿数和参考轴定义必须一致；行星特征阶次不能只靠齿数猜测参考轴。
- TSA 需要足够完整转数；平均段数不足、转速漂移或相位误差会残留非同步成分。
- 边带目标需在频率/阶次分辨率和分析带宽内可分辨，谱线重合不能当作多个独立命中。
- NA4/NB4 的趋势意义需要历史健康方差基线；没有历史时只能使用明确标记的退化指标，不声称具备长期趋势能力。
- 行星慢方法的模态数、分段长度和频带必须受内存与记录长度约束。

## Pipeline 组合

### 定轴指标

```text
标量转频 + 齿数 → 等角重采样 → TSA
→ 规则啮合/残余/差分表示
→ 时域高阶矩 + 啮合谐波/边带 + 倒谱指标
→ 独立证据评估 → 集成诊断
```

差分信号用于突出局部冲击，残余信号用于非同步成分和轴承/其他齿轮分析。两者不能互相替代。

### 行星解调

```text
标量转频 + 行星运动学
→ Level 1 时域证据门控
→ Level 2 窄带/全频带/TSA/高通包络阶次
→ 必要时 Level 3 VMD AM-FM
→ 研究路径 Level 4 SC/SCoh、Level 5 MSB 或 CVS+MED
→ 多证据评估
```

包络阶次、幅值/频率联合解调、循环平稳和双谱关注的物理证据不同。局部背景估计应排除目标主瓣并使用邻近可比较频带，避免窄带滤波后用近零全局背景制造虚高 SNR。`env_kurt` 对磨损和缺齿较敏感，但对局部断齿和裂纹可能与健康重叠，应结合 FM4、TSA 残差、SER/CAR 等路径。

## 错误与不可判定语义

- 缺转频、缺齿数、非法几何或不可实现频带时，不生成物理故障命中；配置畸形应显式报错。
- 快速变速结构化结果进入当前齿轮路径属于前提不满足，不能静默降级为恒速。
- 无历史基线时 NA4/NB4 的退化结果不得解释为长期趋势证据。
- 目标不可分辨、超带宽或共享谱峰时应标记不可评估，而不是 SNR=0 或健康。
- 时域门控未通过只表示当前证据不足，不等于证明设备健康；研究慢方法是否继续由调用策略决定。
- 行星多方法冲突应保留各证据，不通过强行投票制造确定故障位置。

## 复杂度与内存

等角重采样和谱分析通常为 $O(N\log N)$；TSA 额外保存角域与平均序列。VMD 随模态数和迭代次数增长，SC/SCoh 与 MSB 随分段和二维频率网格增长，多方法串联进一步放大峰值内存。生产实时路径只使用受控方法集合，慢方法串行并限制 5 秒数据；通用限制见 [后端架构](../../backend/architecture.md)。
