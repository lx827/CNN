# 诊断业务组合全景

本页只导航系统组合，不复制算法公式、函数签名或状态映射。数学/单位见 [算法索引](algorithms/INDEX.md)，证据/状态唯一规则见 [assessment](backend/assessment.md)，外部字段见 [API](api/backend_api.md)。

## 数据流

```text
原始采样 + 真实通道机械配置
→ 受控窗口/去噪 + 结构化转速工况
→ 对象算法表示 → 分析指标 → 对象评估
→ 规范 Evidence 与共同依赖去重 → 对象 Evaluation
→ 总体 Diagnosis/coverage/一次评分和建议
→ 精确通道缓存 + 批次摘要 + 规范告警/前端
```

纯数值库不依赖 HTTP/ORM；业务不另藏重复数学或阈值解释。转速估计使用原始/去趋势信号，增强信号服务于故障表示，不能先将快速轨迹缩成标量绕过恒速前提。展示截断不改变完整指标。

## 对象与方法

| 入口 | 组合边界 |
|------|----------|
| [轴承](algorithms/bearing/INDEX.md) | 标准包络、高级选带/解卷积/循环平稳各有前提和评估；SC 不被包络覆盖 |
| [定轴/行星](algorithms/gear/INDEX.md) | 参考轴、边带、TSA 与基线各自定义；无行星基线不套定轴阈值 |
| [阶次](algorithms/order/INDEX.md) | 恒速、逐帧和连续相位不同；下游不因阶次图补偿自动支持快变速 |
| [分解](algorithms/decomposition/INDEX.md) | 原时间轴/有效区间、指标/选择/收敛质量分离，不单独判故障 |
| [基础数值](algorithms/numeric/INDEX.md) | 单边幅值/统计/倒谱/显示抽点统一；counts 显示与设备诊断分开 |
| [复合研究](algorithms/composite/INDEX.md) | VMD AM/FM、四阶 MSB、真实 CVS 串联、ICA 与 MSWPEE；不进生产投票/缓存/告警 |

runtime/balanced/exhaustive 选择成本和适用方法，增加方法或去噪变体不增加独立观测。全部诊断结果使用两维状态与 coverage；未知或失败不补成正常，也不默认故障。

## 证据与副作用

Evidence 保存真实记录、对象、方法和依赖。共同依赖形成连通组，组内不重复增票，独立组才进入对象级 normal/anomaly 融合；物理部位命题可以共存。assessment 对合法已有证据直接重评，不重复算法；扣分/权重只应用一次，结论不从分数反推。

部分对象未知时，整体可保留有效对象的 evaluated/partial 结论，但局部未知与覆盖限制必须展示；全部未知则 unknown/null。前端 getDiagnosisView/DiagnosisCoverage 统一显示，不各自解释旧 status、RMS 或概率。

手工重新分析与后台 worker 共用 [批次事务](backend/persistence.md)，保存所有真实通道、channel0/none 批次摘要、原始标记和告警后一次 commit，随后 WS。精确四元键通道查询不借其他去噪/批次，直接重评与原始数据重新分析分开；旧 JSON 不猜新结论。
