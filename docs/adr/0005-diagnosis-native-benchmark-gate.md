# ADR 0005：诊断原生替换的固定向量准入规则

- 状态：已采用准入规则；原生实现尚未采用
- 日期：2026-11-12
- 关联：#79

## 决策

保留生产 Python 算法与质量门控。EMD-signal 只位于 uv 可选 `benchmark` dependency group，adapter 仅供离线比较，显式关闭内部并行并固定种子，不引入生产默认切换。

候选替换以固定 SHA256 输入、原采样率/显式派生率、参数语义、线程与窗口为共同前提。计时保存每次样本、中位数和 P95，内存采用操作系统真实峰值；不把近似、未收敛或不可判定当成正确诊断。公式不同的分解参照保留数学差异，不用逐列模态误差或零重构误差宣称等价。

原生函数粒度由已测热点确定，先比较重复分解、固定矩阵分解复用、公共转频/阶次结果复用、分段工作区和边界复制。接口携带单位、随机种子、状态/收敛与有效区间；连续 float64 输入只读借用，输出有独立 owner，FFI 内不另起线程池。

生产 `max_workers=2`、`ANALYSIS_SEM=1` 继续有效。Windows 进程约束不替代目标 Ubuntu ECS 全机 2C2G 服务余量验证。未测 Rust/C++ 候选没有性能结论；通过同向量正确性、状态与目标资源验收后再决定生产采用。

## 结果存放与执行

生成向量、环境、profile、JSON/CSV、数值表、比较结论与采纳决定详报只保存在显式数据根，不提交仓库。仓库保留源码、冻结配置、原始身份清单和手写运行/接口契约，便于后续用同一输入重现。

完整命令、测量口径、参照语义及所有权草案见 [性能基准运行说明](../benchmarks/diagnosis_performance.md)。候选先作为 benchmark adapter，正确性成立后再比较成本，避免在缺证据时预设某库或语言一定更快。
